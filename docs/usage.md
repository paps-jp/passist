# PAssist 使い方ガイド

PAssist は、このPCで開いている **1つのウィンドウだけ** を、相手にブラウザで一時的に操作してもらうツールです。
**デスクトップ全体や他のウィンドウは絶対に映りません。**

## 登場人物
- **ホスト** … 共有する人（このPC）
- **ゲスト** … 操作する人（ブラウザだけ・インストール不要）

---

## パターンA：同じネットワーク内（一番かんたん・インストール不要）

相手が同じ Wi-Fi / LAN（または同じ Tailscale）にいる場合。

**ホスト**
1. リポジトリ直下で `npm start`
2. 共有したいウィンドウをクリックして選ぶ
3. 表示された **共有URL** の「コピー」を押して相手に送る
   - ※ URL のアドレスが相手から届く経路か確認（同一Wi-Fiなら `192.168.x.x`、Tailscaleなら `100.x.x.x`）。
     違う場合は「外部公開URL欄」に正しいベースURLを入れて「URLを再発行」。

**ゲスト**
4. 送られた URL をブラウザで開く →「クリックして操作を開始」

**ホスト**
5. 「接続リクエストがあります」→ **許可する**

→ 相手はその1ウィンドウだけをマウス／キーボードで操作できます。

---

## パターンB：離れた場所から（インターネット越し・UPnP自動公開）

相手が別の回線にいる場合でも、**クライアントはブラウザだけ**（インストール不要）。
このPCが公開IPを持ち、ルーターのUPnPが有効なら、アプリが自動で公開します。

**ホスト**
1. `npm start`（起動時に UPnP で TCP 8443 を自動開放）
   - 起動ログに `[host] インターネット公開: http://<公開IP>:8443 ...` が出れば成功
   - 公開したくない時は `$env:PASSIST_PUBLIC="0"; npm start`（同一LAN内のみ）
2. ウィンドウを選ぶ → **共有URL（`http://<公開IP>:8443/s/...`）をコピーして相手に送る**

**ゲスト**
3. 送られた **共有URL** をブラウザで開く →「クリックして操作を開始」

**ホスト**
4. **許可する**（または「この端末を信頼」で次回から自動承認）

→ 操作開始。終了はゲストがブラウザを閉じるだけ。

> https にしたい / UPnPが使えない場合は、`cloudflared tunnel --url http://localhost:8443` で得た
> `https://…trycloudflare.com` を「外部公開URL」欄に入れて再発行（この場合 `PASSIST_PUBLIC=0` でOK）。

---

## ホスト画面でできること
- **共有URLコピー** … 相手に渡すリンク
- **許可 / 拒否** … 接続リクエストへの応答
- **この端末を信頼** … チェックして許可すると、その端末は次回から承認なしで接続
- **信頼リンクを発行** … 事前に信頼URLを渡す（相手は初回から承認不要）
- **セッション終了** … 今の接続を切る
- **外部公開URL欄** … トンネル/別IPを使う時にベースURLを指定して再発行

## 自動で効いているセキュリティ
- 選んだ **1ウィンドウだけ**（デスクトップ・他ウィンドウは映らない）
- URLは **トークン付き＋30分で自動失効**
- **ホスト承認制**（信頼済み端末のみ自動）
- 操作は **そのウィンドウの中だけ**。Win / Alt+Tab などの脱出キーはブロック

## 終了のしかた
- ホスト：PAssist の「セッション終了」またはアプリを閉じる（アプリ終了時に公開ポートも自動で閉じる）
- ゲスト：ブラウザを閉じる

## 困ったとき
- **公開URLが出ない（LAN URLになる）**：ルーターの UPnP が有効か／公開IPを持っているか（多段NATだと不可）。
  その場合は Cloudflare トンネルで公開URLを発行。
- **別回線の相手で映像が出ない**：WebRTC が P2P 直結できない NAT の可能性 → `iceServers` に TURN を追加。
- **操作できるが対象が違う**：対象ウィンドウを前面・可視に保つ（同名ウィンドウ対策に HWND 一致を使用）。
